# 하드웨어

## 구성

| 부품 | 연결 | 비고 |
|------|------|------|
| 라즈베리파이 | | 주행과 YOLO 추론을 모두 수행 |
| 카메라 | Picamera2 | 640×480, RGB888. 장착 방향에 맞춰 프레임을 180도 회전합니다 |
| DC 모터 2개 (좌·우) | 모터 드라이버, 채널당 PWM 1핀 + 방향 2핀 | 속도는 PWM duty(0.0~1.0) |
| 부저 | PWM 1핀 | 2,000Hz |

## 핀 배치 (BCM)

| 용도 | 핀 |
|------|----|
| 좌측 모터 속도 (PWMA) | 18 |
| 좌측 모터 방향 (AIN1, AIN2) | 22, 27 |
| 우측 모터 속도 (PWMB) | 23 |
| 우측 모터 방향 (BIN1, BIN2) | 25, 24 |
| 부저 | 12 |

핀 번호는 `config.py`에 모여 있습니다.

## 주행 속도 (PWM duty)

| 상황 | 직진 | 회전 |
|------|------|------|
| 기본 | 0.225 | 0.30 |
| 감속 표지판 인식 후 | 0.20 | 0.16 |

회전 속도가 직진보다 높습니다. 회전 강도가 크면 안쪽 바퀴를 역회전시켜 제자리 회전에
가깝게 돕니다.

## 소프트웨어
