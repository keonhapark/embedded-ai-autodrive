# ADR-0003: 표지판 탐지 — 별도 스레드

## 배경

YOLO 추론은 차선 측정보다 훨씬 무겁습니다. 한 루프에서 차례로 돌리면 추론이 끝날 때까지
조향이 멈춥니다.

## 결정

주행 루프(`lane_tracer`)와 탐지 루프(`object_detector`)를 별도 스레드로 돌리고,
Lock으로 보호한 `shared_state`로 데이터를 주고받습니다.

| | 주행 스레드 | 탐지 스레드 |
|---|---|---|
| 루프 대기 | 0.02초 | 0.1초 |
| 쓰는 것 | 2프레임마다 최신 프레임 | 감지 여부, 신뢰도, 박스 면적, 감지 시각 |
| 읽는 것 | 감지 여부와 신뢰도 | 최신 프레임 |

탐지 스레드는 표지판이 놓이는 프레임 오른쪽 절반만 추론합니다.

## 결과

- 추론이 느려도 조향 주기가 유지됩니다.
- 두 스레드가 주고받는 것이 프레임 한 장과 인식 결과뿐이라 경계가 단순합니다.
- 같은 표지판이 여러 프레임에 걸쳐 감지되므로, 동작별 4초 쿨다운을 두어 표지판 하나에
  한 번만 반응합니다.
