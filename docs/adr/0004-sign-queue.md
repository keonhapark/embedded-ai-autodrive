# ADR-0004: 방향 표지판 큐

## 배경

방향 표지판은 교차로보다 앞에 있습니다. 표지판을 보는 시점과 방향을 바꿔야 하는 시점이
다르고, 교차로에 도착했을 때는 표지판이 이미 화면 밖에 있을 수 있습니다.

## 결정

방향 표지판(직진·좌·우·신호등)을 인식하면 큐에 넣어 둡니다(`store_direction_signs`).
교차로에서 멈추면 가장 먼저 넣은 것을 꺼내 수행하고, 수행을 마치면 큐를 비웁니다.

같은 표지판이 여러 번 쌓이지 않도록 두 가지를 둡니다.

- 직전에 넣은 것과 같은 표지판은 넣지 않습니다.
- 표지판별로 4초, 저장 전체로 3초 쿨다운을 둡니다.

## 결과

- 표지판을 보는 위치와 교차로가 떨어져 있어도 교차로에 도착한 시점에 방향을 바꿉니다.
- 교차로를 지날 때마다 큐를 비우므로 교차로마다 새로 본 표지판으로 판단합니다.
