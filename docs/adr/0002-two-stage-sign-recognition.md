# ADR-0002: 표지판 인식 — 탐지 → 분류 2단계

## 배경

인식할 대상은 방향 표지판 3종(직진·좌·우), 정지·감속·경적 표지판, 신호등입니다. 한
프레임에서 표지판의 위치를 찾는 일과, 찾은 표지판이 무엇인지 가리는 일이 필요했습니다.

## 결정

두 모델을 이어 붙입니다(`object_detector.py`).

1. 탐지 모델(YOLOv8n)이 프레임에서 표지판과 신호등 영역을 찾습니다. 클래스는 `sign`,
   `traffic` 2종입니다.
2. 찾은 영역을 잘라 분류 모델(YOLOv8n-cls, 입력 224px)이 7종으로 나눕니다.

단계마다 거르는 기준을 따로 둡니다.

| 기준 | 값 |
|------|----|
| 탐지 신뢰도 | 0.8 이상 |
| 박스 면적 | 10,000px 이상 |
| 분류 신뢰도 | 0.9 이상 |

## 결과

- 탐지 모델은 `sign`, `traffic` 2종만 다루므로, 인식 대상이 바뀌어도 탐지 클래스는
  그대로 두고 분류 모델의 클래스만 바꾸면 됩니다. 신호등을 적·녹 2종에서 1종으로 합친
  변경도 분류 모델에서만 반영했습니다.
- 영역을 찾았더라도 분류가 불확실하면 버리므로 오인식을 두 번 거릅니다.
